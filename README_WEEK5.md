# Skillora — Week 5 Advanced Order & Project Management

This submission extends the supplied Skillora Week 3 codebase with a professional Week 5 workflow:

Proposal → Accepted → Order/Contract → Project Progress → Delivery → Completed

## New files
- `orders.html` — My Orders / Projects dashboard
- `project-details.html` — detailed project/contract workspace
- `project.css` — responsive dashboard UI
- `project.js` — localStorage data, filtering, milestones, role views, delivery and status interactions

## Advanced features
- Active, pending, completed and cancelled project cards
- Search, status filters and sorting
- Project health overview and metrics
- Contract details, client/freelancer profiles and budget/deadline
- Interactive progress indicator and workflow steps
- Milestone/task completion and milestone creation
- Freelancer and Client view switch
- Delivery submission and client approval flow
- Activity timeline and project messaging
- Responsive mobile layout
- Persistent demo state using localStorage

Open `orders.html` in a browser to start the Week 5 project workspace.

Note: this is a frontend prototype; payment, authentication and server persistence are represented by demo/localStorage behavior.
